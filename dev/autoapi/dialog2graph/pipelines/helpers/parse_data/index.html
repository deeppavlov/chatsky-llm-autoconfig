invoke(raw_data: PipelineRawDataType) → PipelineDataType[source]#

Validate and convert user’s data into list of Dialogs

Parameters:

raw_data (PipelineRawDataType) –

data to parse raw_data.dialogs can be as follows:

[{‘participant’: user or assistant, ‘text’: text}] {‘messages’: [{‘participant’: user or assistant, ‘text’: text}]} [[{‘participant’: user or assistant, ‘text’: text}]] [{‘messages’: [{‘participant’: user or assistant, ‘text’: text}]}] or same in json file presented by file path

raw_data.supported_graph and raw_data.true_graph:

either schemas.DialogGraph or file path

Return type:

PipelineDataType

Returns: PipelineDataType with dialogs and graphs
